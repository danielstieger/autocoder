# Qualitative Brand Association Codebook Generator

This project defines a workflow for creating a robust **codebook for open-ended brand association responses**.

The underlying research question is:

> **“What comes to mind when thinking about [[some brand name here]]?”**

Respondents may answer in different languages and with anything from a single word to a longer phrase. The goal is to transform these qualitative responses into a structured set of categories that can later be used for systematic coding and quantitative analysis.

The assistant acts as a **senior market researcher** responsible for inductively developing, testing, refining, and finalizing the codebook.
